# QuickBlog - AI Powered Blog Platform

QuickBlog is a full stack AI-powered blogging platform built using the MERN stack. Users can create, manage, and publish blogs with modern UI and AI-integrated features.

## 🚀 Features

* User Authentication
* Create, Edit and Delete Blogs
* AI Powered Blog Generation
* Responsive UI
* Admin Dashboard
* MongoDB Database Integration
* REST API Backend
* Image Upload Support

## 🛠️ Tech Stack

### Frontend

* React JS
* Tailwind CSS
* Axios

### Backend

* Node.js
* Express.js

### Database

* MongoDB

### Other Tools

* Gemini API / OpenAI API
* ImageKit / Cloudinary
* JWT Authentication

## 📂 Project Structure

client/ → Frontend React Application
server/ → Backend APIs and Database Logic

## ⚙️ Installation

### Clone Repository

```bash
git clone https://github.com/sakshigoswami05/QuickBlog.git
```

### Install Dependencies

Frontend:

```bash
cd client
npm install
```

Backend:

```bash
cd server
npm install
```

### Run Frontend

```bash
npm run dev
```

### Run Backend

```bash
npm start
```
